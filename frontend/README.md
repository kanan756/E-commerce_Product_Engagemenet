# KALVÉ - Luxury E-commerce Platform

A premium, bespoke e-commerce platform built for high-end luxury products, featuring a sophisticated dark theme with gold accents, advanced filtering, and a seamless responsive design.

## 🚀 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Library:** [React](https://react.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Deployment:** Vercel (Recommended)

## ✨ Core Features & Functionalities

- **Advanced Dual-Filtering System:** Seamlessly filter the product gallery by both **Category** (Chess, Basins, Tables, Wall Art) and **Color Theme** (Black Gold, Pink White, Blue Gold, Black Premium, Red White, Green) simultaneously.
- **Fully Responsive Design:** The platform is meticulously crafted to look stunning on all devices, from mobile phones (Android/iOS) and tablets to desktop monitors and ultra-wide LED TVs.
- **Interactive Mobile Navbar:** A custom slide-out hamburger menu designed specifically for mobile users, ensuring smooth navigation on smaller screens.
- **Dynamic Product Detail Pages:** Individual product pages (`/products/[id]`) that showcase high-resolution, uncropped images (`object-contain`) and feature intricate details, pricing, dimensions, and engagement actions (Wishlist, Compare, Artisan Chat).
- **Cinematic Hero Section:** An auto-fading background slider on the homepage that elegantly rotates through hero products.
- **Bespoke Contact Experience:** A fully styled contact/enquiry page with custom dark-themed inputs and bespoke Atelier details.
- **Uniform Image Grids:** CSS object-fitting (`object-cover`) ensures that the product grid remains perfectly aligned and geometrically uniform regardless of the original image dimensions.

## 🛠️ Getting Started Locally

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📦 Deployment on Vercel

The easiest way to deploy this Next.js app is to use the [Vercel Platform](https://vercel.com/new).

1. Push this repository to GitHub.
2. In Vercel, click **Add New Project**.
3. Import the repository.
4. Important: Set the **Root Directory** to `frontend`.
5. Keep the Framework Preset as **Next.js**.
6. Click **Deploy**.
